GoPro Connect Kotlin Multiplatform SDK

The GoPro Connect SDK provides a Kotlin Multiplatform API for discovering cameras, connecting, observing live camera state, controlling capture, and retrieving media.

This documentation covers the SDK API reference and the shared model types used throughout the SDK.

1. Introduction

The SDK is organized around:

  • ConnectSdk as the entry point

  • Connector as the shared operation handle

  • CameraDevice as the camera representation used throughout the SDK

  • Use case classes in com.gopro.connect.api.usecase for camera operations

Platform support is provided via KMP targets (Android and Apple).

2. Setup

Initialize the SDK once at app startup, then obtain a shared Connector. The clientKey passed to setup is required and must be at least 16 characters long.

Android

import android.app.Application
import com.gopro.connect.api.ConnectSdk
import com.gopro.connect.api.model.Connector

class MyApp : Application() {
    lateinit var connector: Connector

    override fun onCreate() {
        super.onCreate()
        ConnectSdk.setup(this, "sample-client-key")
        connector = ConnectSdk.connector()
    }
}

3. Scanning for Devices

Use StartDeviceScanSessionUseCase to begin discovery and GetScanningStateUseCase to observe ScanState. Keep the returned session for as long as the owning screen or workflow needs discovery, then call release().

import com.gopro.connect.api.model.ScanState
import com.gopro.connect.api.usecase.GetScanningStateUseCase
import com.gopro.connect.api.usecase.StartDeviceScanSessionUseCase
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.job
import kotlinx.coroutines.launch

fun startScanning(scope: CoroutineScope, connector: com.gopro.connect.api.model.Connector) {
    val startScan = StartDeviceScanSessionUseCase(connector)
    val scanState = GetScanningStateUseCase(connector)

    val scanSession = startScan()

    scope.launch {
        scanState().collect { state ->
            when (state) {
                ScanState.Idle -> Unit
                ScanState.Scanning -> Unit
                is ScanState.Error -> {
                    // state.reason is ScanError
                }
            }
        }
    }

    scope.coroutineContext.job.invokeOnCompletion {
        scanSession.release()
    }
}

4. Connecting to a Camera

Retrieve devices with GetCameraDevicesUseCase, then connect with ConnectToDeviceUseCase. Connection updates are exposed via each device's DeviceConnectionStatus streams. If you no longer want a camera to participate in remembered reconnect flows, call connector.forgetDevice(device).

import com.gopro.connect.api.model.NetworkType
import com.gopro.connect.api.usecase.ConnectToDeviceUseCase
import com.gopro.connect.api.usecase.GetCameraDevicesUseCase
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.launch

fun connectFirstDevice(scope: CoroutineScope, connector: com.gopro.connect.api.model.Connector) {
    val getDevices = GetCameraDevicesUseCase(connector)
    val connectToDevice = ConnectToDeviceUseCase(connector)

    scope.launch {
        getDevices().collect { devices ->
            val device = devices.firstOrNull() ?: return@collect

            val connected = connectToDevice(
                device = device,
                connectionTypes = listOf(NetworkType.BLE, NetworkType.WIFI),
                rememberDevice = true,
            )

            if (connected) {
                // Observe primary connection lifecycle
                scope.launch {
                    device.primaryConnectionStatus.collect { status ->
                        // status is DeviceConnectionStatus
                    }
                }
            }
        }
    }
}

5. Reading Camera State

CameraDevice exposes state surfaces that update over time:

  • CameraBatteryState

  • CameraCaptureState

  • CameraStorageState

  • CameraConnectivityState

  • CameraDeviceInfo

  • CameraSystemState

  • CameraStreamState

CameraDevice also implements the shared Device contract, so identity and connection properties such as displayName, model, firmwareVersion, primaryConnectionStatus, connectionStatuses, and isRemembered are always available.

import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.launch

fun observeCameraState(scope: CoroutineScope, device: com.gopro.connect.api.model.CameraDevice) {
    device.deviceInfo?.let { info ->
        scope.launch { info.name.collect { name -> /* update title */ } }
    }

    device.batteryState?.let { battery ->
        scope.launch { battery.batteryPercentage.collect { percent -> /* 0..100 */ } }
    }

    device.captureState?.let { capture ->
        scope.launch { capture.isShutterOn.collect { isRecording -> /* update UI */ } }
    }

    device.storageState?.let { storage ->
        scope.launch { storage.storagePercentage.collect { used -> /* update UI */ } }
    }

    device.systemState?.let { system ->
        scope.launch { system.isCameraReady.collect { ready -> /* enable controls */ } }
    }

    device.streamState?.let { stream ->
        scope.launch { stream.isPreviewAvailable.collect { available -> /* enable preview */ } }
    }

    scope.launch {
        device.hasNewFootageAvailable.collect { hasNew -> /* refresh gallery badge */ }
    }
}

6. Recording

Use StartRecordingUseCase and StopRecordingUseCase. Both return DeviceCommandResult.

import com.gopro.connect.api.model.DeviceCommandResult
import com.gopro.connect.api.usecase.StartRecordingUseCase
import com.gopro.connect.api.usecase.StopRecordingUseCase

suspend fun toggleRecording(device: com.gopro.connect.api.model.CameraDevice) {
    val start = StartRecordingUseCase()
    val stop = StopRecordingUseCase()

    when (val result = start(device)) {
        is DeviceCommandResult.Success -> {
            // later...
            stop(device)
        }
        is DeviceCommandResult.Failed -> {
            // result.error may be null
        }
    }
}

7. Media

Use CameraDeviceGetMediaListUseCase to list files, then retrieve metadata, stream files, download thumbnails, or delete media.

import com.gopro.connect.api.model.DeviceCommandResult
import com.gopro.connect.api.model.ThumbnailSize
import com.gopro.connect.api.usecase.CameraDeviceDeleteMediaUseCase
import com.gopro.connect.api.usecase.CameraDeviceDownloadThumbnailUseCase
import com.gopro.connect.api.usecase.CameraDeviceGetMediaFileStreamUseCase
import com.gopro.connect.api.usecase.CameraDeviceGetMediaListUseCase
import com.gopro.connect.api.usecase.CameraDeviceGetMediaItemMetadataUseCase

suspend fun loadMedia(device: com.gopro.connect.api.model.CameraDevice) {
    val getMediaList = CameraDeviceGetMediaListUseCase()
    val downloadThumbnail = CameraDeviceDownloadThumbnailUseCase()
    val getMetadata = CameraDeviceGetMediaItemMetadataUseCase()
    val getFileStream = CameraDeviceGetMediaFileStreamUseCase()
    val deleteMedia = CameraDeviceDeleteMediaUseCase()

    val mediaResult = getMediaList(device)
    val firstMedia = when (mediaResult) {
        is DeviceCommandResult.Success -> mediaResult.data.firstOrNull()
        is DeviceCommandResult.Failed -> null
    } ?: return

    val thumbResult = downloadThumbnail(
        device = device,
        filePath = firstMedia.filePath,
        size = ThumbnailSize.SMALL,
    )

    when (thumbResult) {
        is DeviceCommandResult.Success -> {
            val bytes = thumbResult.data
            // render thumbnail bytes
        }
        is DeviceCommandResult.Failed -> {
            // thumbResult.error may be null
        }
    }

    getMetadata(device, firstMedia.filePath)
    getFileStream(device, firstMedia.filePath, highResolution = true)
    deleteMedia(device, firstMedia.filePath)
}

8. Settings

Use CameraDeviceGetSettingsUseCase to observe available settings and CameraDeviceSetSettingUseCase to apply updates. For capture-mode selection flows, use CameraDeviceGetCaptureModeCapabilitiesUseCase to discover what the camera supports and CameraDeviceSetCaptureModeUseCase to apply a new CaptureMode.

import com.gopro.connect.api.usecase.CameraDeviceGetSettingsUseCase
import com.gopro.connect.api.usecase.CameraDeviceSetSettingUseCase
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.launch

fun observeAndUpdateSettings(
    scope: CoroutineScope,
    device: com.gopro.connect.api.model.CameraDevice,
) {
    val getSettings = CameraDeviceGetSettingsUseCase()
    val setSetting = CameraDeviceSetSettingUseCase()

    scope.launch {
        getSettings(device).collect { descriptors ->
            val setting = descriptors.firstOrNull() ?: return@collect
            val option = setting.options.firstOrNull() ?: return@collect
            setSetting(device, setting, option)
        }
    }
}

9. Preview Streaming

Use CameraDeviceStartPreviewUseCase and CameraDeviceStopPreviewUseCase to control preview streaming on a connected camera.

Preview rendering is platform-specific:

  • On Android, CameraDeviceCreatePreviewStreamConfigUseCase returns a PreviewStreamConfig containing the preview URI, Media3 extractors, and orientation/video-size flows.

  • On Apple, CameraDeviceCreatePreviewStreamConfigUseCase binds the preview stream to a caller supplied hosting view and returns a PreviewStreamConfig that should be released when the preview session ends.

CameraStreamState helps you decide when preview is supported and available before you start the preview workflow.

10. Device Management

Use CameraDevicePowerDownUseCase to power down a connected camera and CameraDeviceFormatSdCardUseCase to format the SD card.

If your app supports reconnect preferences, use connector.forgetDevice(device) to remove a camera from the remembered-device list after disconnecting.
