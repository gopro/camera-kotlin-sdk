GoPro Connect SDK/com.gopro.connect.api.usecase

Package-level declarations

Use case classes for camera operations. Common entry points include StartDeviceScanSessionUseCase, GetCameraDevicesUseCase, ConnectToDeviceUseCase, CameraDeviceStartRecordingUseCase, CameraDevicePowerUpUseCase, CameraDeviceDownloadMediaToDiskUseCase, and CameraDeviceCreateSubmodeUseCase. Each use case is constructed with a Connector when needed and invoked via operator fun invoke(...).
