GoPro Connect SDK/com.gopro.connect.api.model

Package-level declarations

Shared model types and state surfaces. Includes canonical types such as Device, DeviceConnectionStatus, DeviceCommandResult, ScanState, CaptureMode, CameraSettingDescriptor, CameraMediaItem, and CameraMediaMetadata. CameraDevice provides access to camera properties and state wrappers such as CameraBatteryState, CameraCaptureState, and CameraStorageState.
