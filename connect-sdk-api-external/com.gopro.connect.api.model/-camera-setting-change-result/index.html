CameraSettingChangeResult

sealed class CameraSettingChangeResult

Result of a typed setting change attempt via CameraDeviceSetSettingUseCase.

Callers should handle each subtype for a complete failure-path UX:

  • Success — the camera confirmed the change was applied.

  • Unsupported — the setting is not supported by the connected camera.

  • UnknownOption — the option is not in the current typed mapping slice.

  • Unavailable — the option is currently blacklisted by camera filter rules.

  • Locked — the setting or option is currently locked (read-only).

  • CommandFailed — the protocol command was rejected or not acknowledged.

  • Timeout — the camera did not confirm the change within the deadline.
