Factory

data class Factory(val id: CameraSubmodeId, val behavior: CameraSubmodeBehavior = CameraSubmodeBehavior(), val controls: CameraSubmodeControlCapabilities = CameraSubmodeControlCapabilities(), val title: CameraSubmodeTitle = CameraSubmodeTitle(), val iconId: CameraSubmodeIconId = CameraSubmodeIconId.UNKNOWN, val isVisible: Boolean = true, val isModified: Boolean = false, val isEditable: Boolean = false, val isVisibilityEditable: Boolean = false) : CameraSubmode

Factory-shipped submode from the camera trail registry or camera definition metadata.

isVisible reflects whether the camera currently exposes the submode in normal preset browsing. isVisibilityEditable controls whether the user can toggle that state.
