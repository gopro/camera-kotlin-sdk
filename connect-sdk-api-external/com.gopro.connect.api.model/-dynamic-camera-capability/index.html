DynamicCameraCapability

enum DynamicCameraCapability : CameraCapabilityId, Enum<DynamicCameraCapability>

Camera capabilities whose availability is transport-gated and changes during a session.

Use CameraCapabilitiesRepository.isSupported for the static support check and CameraCapabilitiesRepository.isAvailable / CameraCapabilitiesRepository.observeAvailable for runtime transport-gated availability.
